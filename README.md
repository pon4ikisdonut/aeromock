# AeroMock GPS (Android 8.0 – 17)

Полнофункциональное Android-приложение для GPS-спуфинга на **Kotlin + Jetpack Compose + Material 3 (Dynamic Color)**.

## Основные функции
- **Интерактивная карта (OSMdroid / OpenStreetMap)**: работает без API-ключей, тап по карте ставит пин, долгий тап мгновенно телепортирует.
- **Плавающий джойстик (`SYSTEM_ALERT_WINDOW`)**: работает поверх любых приложений, перетаскивается за верхнюю плашку, имеет пресеты скорости (Пешком / Бег / Вело / Авто / Трасса).
- **Симулятор маршрутов и импорт GPX**: рисование маршрута прямо на карте или загрузка `.gpx` файлов, режимы `Один раз`, `По кругу`, `Туда-обратно`.
- **Реалистичная телеметрия**: настраиваемая точность (`Accuracy`), высота (`Altitude`), интервал обновления и **микро-дрейф (Anti-Static Jitter)**, чтобы координаты не выглядели замороженными.
- **Избранное и поиск**: поиск по координатам (`lat, lon`) или названию места (Nominatim), быстрый телепорт.

## Как получить APK
1. **Через GitHub Actions (без установки Android Studio)**:
   Залейте содержимое архива в репозиторий на GitHub -> откройте вкладку **Actions** -> запустите/дождитесь workflow **Build Debug APK** -> скачайте готовый `app-debug.apk` из Artifacts. (Готовые билды уже есть в данном репозиторие, в Actions -> Artifacts)
2. **Локально в Android Studio / Gradle**:
   Откройте папку в Android Studio и нажмите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** или выполните `gradle assembleDebug`.

## Настройка на телефоне (Android)
1. Включите **Для разработчиков** (*Настройки -> О телефоне -> 7 раз по Номеру сборки*).
2. В разделе **Для разработчиков -> Выбрать приложение для фиктивных местоположений** укажите **AeroMock GPS**.
3. Выдайте разрешение на геолокацию, уведомления и показ поверх других окон (для джойстика).
